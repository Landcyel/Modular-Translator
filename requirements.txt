# 1) torch / torchaudio — choose a variant by hardware:
#    CPU build (machines without a GPU):
#      pip install torch==2.11.0+cpu torchaudio==2.11.0+cpu \
#        --index-url https://download.pytorch.org/whl/cpu
#    GPU cu128 build (NVIDIA + CUDA 12.8):
#      pip install torch==2.11.0+cu128 torchaudio==2.11.0+cu128 \
#        --index-url https://download.pytorch.org/whl/cu128
#    GPU cu128 build — Aliyun mirror (faster in China; note you MUST use
#    --find-links rather than --index-url: this mirror is a flat file list, not a
#    PEP 503 index, and --index-url would report "versions: none". Verified to
#    contain torch-2.11.0+cu128-cp314-cp314-win_amd64.whl):
#      pip install torch==2.11.0+cu128 torchaudio==2.11.0+cu128 \
#        --find-links https://mirrors.aliyun.com/pytorch-wheels/cu128
#    Selected automatically at runtime by app/torch_runtime.py (GPU detected → CUDA, else CPU).

# 2) moss-transcribe-diarize==0.1.0 — local source package (not on PyPI):
