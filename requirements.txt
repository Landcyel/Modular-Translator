# 1) torch / torchaudio —— 需按硬件选择变体：
#    CPU 版（无 GPU 机器）：
#      pip install torch==2.11.0+cpu torchaudio==2.11.0+cpu \
#        --index-url https://download.pytorch.org/whl/cpu
#    GPU cu128 版（NVIDIA + CUDA 12.8）：
#      pip install torch==2.11.0+cu128 torchaudio==2.11.0+cu128 \
#        --index-url https://download.pytorch.org/whl/cu128
#    GPU cu128 版 —— 阿里云镜像源（国内加速；注意必须用 --find-links 而非 --index-url：
#    该镜像是 flat 文件列表，非 PEP 503 索引，--index-url 会报 versions: none。
#    已验证包含 torch-2.11.0+cu128-cp314-cp314-win_amd64.whl）：
#      pip install torch==2.11.0+cu128 torchaudio==2.11.0+cu128 \
#        --find-links https://mirrors.aliyun.com/pytorch-wheels/cu128
#    运行时由 app/torch_runtime.py 自动选择（探测 GPU → CUDA，否则 CPU）。

# 2) moss-transcribe-diarize==0.1.0 —— 本地源码包（不在 PyPI）：
